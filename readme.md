# Bangalore House Price Prediction

Built an end-to-end House Price Prediction web application using Python, Scikit-Learn, Flask, HTML, CSS, and JavaScript. Developed and trained a machine learning model on Bangalore housing data, performed data cleaning, feature engineering, outlier removal, and hyperparameter tuning. Exposed the model through Flask REST APIs and integrated it with a responsive frontend for real-time price prediction.

## Tech Stack

- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy
- HTML/CSS/JavaScript
